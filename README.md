# 🔄 Copycat Revive Watch

A lightweight, static web tool for Torn City faction members to quickly check revive status of their faction.

## 🚀 Live Demo

[**Visit Copycat Revive Watch**](https://YOUR-USERNAME.github.io/revive-watch/)

## ✨ Features

- **Dark Theme** - Easy on the eyes, perfect for late-night Torn sessions
- **Instant Status** - Shows which members are revivable with color-coded badges
- **Privacy First** - API keys stay in your browser, never stored anywhere
- **Mobile Friendly** - Works on desktop, tablet, and phone

## 🎯 How It Works

1. Enter your Torn API key and faction ID
2. Click "Check Revive"
3. View your faction members with revive status:
   - 🟢 **REVIVABLE** - Ready for revival
   - 🔴 **NOT REVIVABLE** - Not currently revivable

## 🛠️ Tech Stack

- Pure HTML, CSS, JavaScript
- Torn City API v2
- Font Awesome icons
- GitHub Pages hosting

## 🔒 Security

- All API calls are made directly from your browser to Torn's servers
- No data is stored or collected
- Your API key never touches our servers
